# Vertex.web

Página de Vertex.web hecha con React + Vite.

## Correr en tu computadora

```
npm install
npm run dev
```

## Publicar

```
npm run build
```

Se crea la carpeta `dist`. Si Netlify está conectado a este repositorio, lo hace solo con cada cambio (ver `netlify.toml`).

## Dónde cambiar cosas

- `src/datos.js`: correo, Facebook, servicios, pasos, preguntas y opciones del formulario.
- `src/legal.js`: aviso de privacidad y términos.
- `src/estilos.css`: colores y diseño.
